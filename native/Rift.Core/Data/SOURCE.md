# Source des files de jeu

queues.json : https://static.developer.riotgames.com/docs/lol/queues.json (17 septembre 2026).
client-queues-fr.json : champs id/name/description/gameSelectModeGroup/gameSelectCategory extraits de https://raw.communitydragon.org/latest/plugins/rcp-be-lol-game-data/global/fr_fr/v1/queues.json (17 septembre 2026).

CommunityDragon distribue les données extraites du client Riot ; ce miroir communautaire n’est pas une API officielle Riot. Les données et noms de League of Legends appartiennent à Riot Games. Le programme peut actualiser cette seconde source sans transmettre de clé Riot.
