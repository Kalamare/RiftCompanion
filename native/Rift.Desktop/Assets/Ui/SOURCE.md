# Icônes officielles Riot

Fichiers PNG originaux, téléchargés le 16 septembre 2026 depuis les sources Riot.

- Documentation : https://developer.riotgames.com/docs/lol#data-dragon_data-assets
- Tableau de scores : https://ddragon.leagueoflegends.com/cdn/5.5.1/img/ui/ (minion.png, items.png, score.png, champion.png, spells.png). Riot documente explicitement ces icônes sous 5.5.1 ; elles ne suivent pas nécessairement le patch actuel.
- Rôles : https://static.developer.riotgames.com/docs/lol/ranked-positions.zip ; Position_Gold-{Top,Jungle,Mid,Bot,Support}.png renommés role-*.png. La variante dorée est décorative et ne représente pas le rang du joueur.
- Balises : https://ddragon.leagueoflegends.com/cdn/16.18.1/img/item/3340.png et 2055.png, renommés item-*.png. Version obtenue via https://ddragon.leagueoflegends.com/api/versions.json au téléchargement.

Ces petites ressources sont livrées avec l’application et décodées avant révélation du profil, hors du thread UI. Aucun appel réseau supplémentaire lors de l’affichage. Les champions et objets des matchs continuent à utiliser le catalogue dynamique Data Dragon.

Les victoires, morts et assists conservent les pictogrammes vectoriels locaux : aucun équivalent dédié identifié dans les ressources documentées utilisées ici. Les illustrations de balises représentent les statistiques de vision, sans prétendre être une icône dédiée au score de vision.

League of Legends et les assets associés appartiennent à Riot Games. Leur inclusion ne constitue pas une approbation de Rift Companion par Riot Games.
